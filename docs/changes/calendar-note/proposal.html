Calendar-Note is an Obsidian calendar built around Event Notes. Create, overlap, and reschedule local events without iCal. Click an event to open its note and add a link to the Daily Note for that event's date.

User story and V1 scope

As an Obsidian user, you want to plan local events in a weekly calendar and optionally subscribe to external calendars. Clicking any event should open its note and create an entry in the correct Daily Note. Rescheduling must preserve the same Event Note.

Daily Notes integration

Use the event's effective start date in the display time zone, rather than the date of the click. For example, clicking an October 22 event on October 23 must update Daily Notes/2026-10-22.md. All-day events retain their original date without a time-zone conversion that shifts the day.

  1. Ensure that the Event Note exists before resolving the Daily Note. When core Daily Notes is enabled, reuse its folder, custom format, and template. Create missing folders and journal files.
  2. When core Daily Notes is disabled, use Calendar-Note's Daily Note path setting, defaulting to [Daily Notes]/YYYY-MM-DD. Other plugins are not prerequisites.
  3. Find ## Event. If absent, append that section to the body. If present, append the bullet within it, before the next heading at the same or a higher level. Preserve existing text and other sections.
  4. The bullet links to the Event Note and includes the event time. Reopening the same event updates the same entry. Different events retain separate links even when their titles match.
  5. If the start date changes, move only the entry managed by Calendar-Note to the new date. Changes within the same day update its time. Do not remove unrelated text, handwritten bullets, or Event Note content.

Event creation and time editing

Local events come from Event Note frontmatter, without a remote subscription or a required separate database. Creation resolves a safe path, creates the note, and then adds the event and journal entry. Any occupied time may hold another event.

Compact frontmatter and stable identity

Local events normally need only event_id, start, and end. Add all_day: true for all-day events. Use ISO timestamps with offsets. Collapse properties in the UI while retaining readable, exportable Markdown.

Imported events add only necessary source references. source identifies the subscription and UID; recurring events also retain the original recurrence_id. Keep full provider data in the subscription cache instead of duplicating it in every note. Preserve user-defined properties when updating managed fields.

Use subscriptionId + UID for single imported events and subscriptionId + UID + original occurrence start / RECURRENCE-ID for recurring occurrences. Local events use an immutable event_id. The effective start time is editable and must not become a mutable identity. Changing times, titles, or note filenames must still open the same note.

When a user edits times in Event Note frontmatter, reparse and validate the interval before updating the calendar. Invalid intervals show an error instead of creating new events. Daily Notes are an index; handwritten bullets are not parsed as a second event source.

Event Note path format

A full path format determines both folders and filename. Dates use the start time at creation. Rescheduling does not automatically move an existing note. The default is [Calendar Notes]/{title}, with a sanitized event-title filename; date-based folder layouts remain configurable.

FormatResult for October 23, 2026
[Calendar Notes]/{title}Calendar Notes/Product strategy Q4 Roadmap.md
[Meetings]/YYYY/MM/DD/{title}Meetings/2026/10/23/Product strategy Q4 Roadmap.md
YYYY/MMMM/YYYY-MMM-DD/{title}English locale: 2026/October/2026-Oct-23/Product strategy Q4 Roadmap.md
[Meetings]/{calendar}/GGGG/[W]WW/{title}Meetings/Work/2026/W43/Product strategy Q4 Roadmap.md

The original title is "Product strategy / Q4: Roadmap?". Replace invalid filename characters with spaces and collapse repeated whitespace. Preserve the original title in the note heading, escaping Markdown syntax when necessary.

Date tokens, [literal] text, locales, and escaping use Moment, matching the formatting engine described in the Daily Notes documentation. {title}, {calendar}, and {uid} are Calendar-Note extensions rather than native Daily Notes variables. See the Moment documentation for date formats.

  1. Protect event variables before formatting dates, then insert sanitized values. YYYY in a title must remain text, and slashes in titles must not create folders. Preserve bracketed literals.
  2. Sanitize control characters, unsafe filename characters, trailing dots/spaces, and Windows reserved names. Limit UTF-8 byte length without splitting Unicode characters, leaving room for extensions and collision suffixes. Empty names become "Untitled event".
  3. Accept only Vault-relative paths. Reject absolute paths, drive prefixes, parent traversal, and unknown variables. Keep exactly one .md extension.
  4. Resolve occupied filenames as Title (2).md without overwriting unrelated files. Reopen the original path for the same event. Use event locks, case folding, and Unicode normalization to avoid duplicate creation.

Optional iCal subscriptions

The local calendar is usable immediately, with subscription settings left blank. Poll a source only after a valid URL is configured. HTTPS and webcal URLs need not end in .ics; validate the response content. Local events do not pass through a remote service.

ScenarioExpected V1 behavior
Normal refreshPoll every 15 minutes by default and support manual refresh. Use Obsidian requestUrl, convert webcal to HTTPS, and honor ETag/Last-Modified when available.
No sources or blank URLsSchedule no remote requests and report no connection errors. Local event creation, resizing, Event Notes, and Daily Notes continue to work.
One source failsRetain valid cached data and show last success, failure time, retry, and backoff. Do not clear other subscriptions or local events.
Recurrence and cross-day eventsSupport RRULE, RDATE, EXDATE, RECURRENCE-ID overrides, and STATUS:CANCELLED. All-day DTEND is exclusive. Expand only within the visible range.
Time zones and DSTHandle VTIMEZONE, TZID, UTC, and floating times. Interpret floating times in the display zone and flag unknown zones. The prototype is fixed to Asia/Taipei.
Local time overrideRefresh the original source event while displaying the Event Note's local override. Show differences and allow reset without silently discarding edits.
Cancellation or source removalKeep Event Notes and journal entries. Existing notes remain readable; show that their source was canceled or removed.
LifecyclePoll only while Obsidian and the plugin are running. Show cache on startup, refresh when needed after resume, and remove timers on unload.

Keep private subscription URLs in plugin settings, not notes, journals, logs, or analytics. Do not execute provider HTML. The prototype uses local sample data; browser fetch/CORS results do not establish whether a subscription works through Obsidian.

Acceptance criteria

  • No iCal: With all URLs cleared, create local events and both note types, edit times, and reload persisted data.
  • Past events: Clicking an October 22 event on October 23 adds a link only to the October 22 Daily Note's Event section.
  • Journal preservation: Create missing journals/sections; append without replacing existing bullets or following sections. Reopening an event leaves one entry.
  • Creation entry points: Empty slots prefill the correct time. Right-clicking a covered slot can create a second or third event.
  • Overlap: Three overlapping events remain distinguishable, clickable, and editable. Touching intervals do not count as overlap.
  • Both resize edges: The top changes only start; the bottom changes only end. Enforce 15 minutes, restore canceled/invalid operations, and avoid accidental creation.
  • Frontmatter: Local events need three fields. Time edits preserve body text, unrelated properties, and note paths.
  • Stable links: Time changes reopen the same note, update the existing bullet, and move it when the start date changes.
  • Separate paths: Event Notes support date and event variables. Daily Notes follow the core custom format or independently configured fallback.
  • Safe filenames: Handle slashes, colons, reserved names, empty titles, and long Unicode/emoji text. Different events never overwrite each other's files.
  • iCal reliability: Source failures do not block other sources or local features. Rescheduling imported events stores local overrides without upstream writes.
  • Complete plugin: Validate recurrence exceptions, DST, midnight crossings, exclusive all-day end dates, manual note moves, and file-write failures separately.
