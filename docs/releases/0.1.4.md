# Calendar-Note 0.1.4

The event details dialog now shows the Event Note itself and makes it clearer where the note will open.

## Event details dialog

- The dialog shows the Event Note's text below its properties, read-only and scrollable, so you can check the note without opening it.
- When notes in the same folder start with the same name as the Event Note, such as `Standup (2).md` or `Standup draft.md` beside `Standup.md`, the note's path becomes a dropdown. Picking one binds the event to that note, as **Change…** does, without opening it. Daily and Weekly Notes and notes that already hold another event are not offered.
- **Beside calendar** and **New tab** are replaced by three buttons: **Left**, **Open in new tab**, and **Right**. The central **Open in new tab** is emphasized and opens the note on the calendar's far side, as in 0.1.3. **Left** and **Right** open it in a new tab in the pane on that side of the calendar, or split the calendar on that side when no pane is there. Each button's icon points to where the note opens.

## Install

**Download the [Calendar-Note 0.1.4 ZIP](https://github.com/rightson/calendar-note/releases/download/0.1.4/calendar-note.zip)**, extract it, and replace the `calendar-note` folder in `<Vault>/.obsidian/plugins/`, or update through BRAT. See the [installation guide](https://github.com/rightson/calendar-note/blob/main/docs/manuals/INSTALLATION.md) for safe updates.

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. The changes are covered by automated tests; the dialog has not had native Obsidian QA. The [0.1.0 verified scope](https://github.com/rightson/calendar-note/blob/main/docs/releases/0.1.0.md#compatibility-and-verification) still describes what was checked in Obsidian.
