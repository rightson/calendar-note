# Calendar-Note 0.1.1

A maintenance release that makes Daily Note entries reliable and improves calendar subscription imports.

## Daily Notes

- Clicking an event no longer fails with "Tracked Daily Note entry was edited or moved". A background scan could record a Daily entry that no longer matched the note; scans now queue behind clicks and moves.
- Entries are recognized by the Event Note they link to, so a stale time or alias is rewritten in place and repeated entries collapse to one. Lines written in your own words are never changed.
- Opening an event adds its Daily entry back if it was removed. Source updates and drag moves still ask you to relink an entry you rewrote.
- New Daily Notes use an `## Events` section with entries directly below the heading. Existing `## Event` sections keep working.
- An unclosed code block at the end of a Daily Note no longer causes a new entry on every click.
- Deleted Event or Daily Notes are recreated on the next click, and a linked Event Note opens at its linked path instead of being reported as moved.

## Calendar subscriptions

- Feeds with a UTF-8 BOM, zero-duration events, multiple `VCALENDAR` streams, `RDATE;VALUE=PERIOD`, or orphan recurrence exceptions now import.
- `METHOD:CANCEL` delta feeds report a specific error instead of removing unrelated events, and subscription failures show privacy-safe error categories.
- Rapid subscription setting changes no longer save stale values.

## Install

**Download the [Calendar-Note 0.1.1 ZIP](https://github.com/rightson/calendar-note/releases/download/0.1.1/calendar-note.zip)**, extract it, and replace the `calendar-note` folder in `<Vault>/.obsidian/plugins/`, or update through BRAT. See the [installation guide](https://github.com/rightson/calendar-note/blob/main/docs/manuals/INSTALLATION.md) for safe updates.

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. The changes in this release are covered by automated tests; native Obsidian QA was not repeated, so the [0.1.0 verified scope](https://github.com/rightson/calendar-note/blob/main/docs/releases/0.1.0.md#compatibility-and-verification) still describes what was checked in Obsidian.
