# Calendar-Note 0.1.0

Calendar-Note is an Obsidian calendar for local events, Event Notes, Daily Notes, Weekly Notes, and optional read-only iCal subscriptions.

## Highlights

- Week, Day, Month, Year, Custom days, and List calendar views.
- Local events stored as Markdown Event Notes and linked from the corresponding Daily Note.
- Optional HTTPS and `webcal://` calendar feeds, with cached events and change history.
- Daily and Weekly Note integration with configurable formats, folders, templates, and week rules.

## Install

**Download the [Calendar-Note 0.1.0 ZIP](https://github.com/rightson/calendar-note/releases/download/0.1.0/calendar-note.zip)**, extract it, and copy its whole `calendar-note` folder into `<Vault>/.obsidian/plugins/`. In Obsidian, open **Settings → Community plugins**, enable community plugins if needed, then enable Calendar-Note and reload if prompted. For file layout, safe updates, and troubleshooting, see the [installation guide](https://github.com/rightson/calendar-note/blob/main/docs/manuals/INSTALLATION.md).

You can also install Calendar-Note with BRAT: install BRAT from Community Plugins, run **BRAT: Add a beta plugin for testing**, and enter `rightson/calendar-note`. The plugin has not been submitted to the Community directory, so it is not yet available through Obsidian's built-in plugin browser. See the [installation guide](https://github.com/rightson/calendar-note/blob/main/docs/manuals/INSTALLATION.md#install-with-brat) for details.

## Compatibility and verification

This release requires Obsidian 1.14.5 or later and supports desktop Obsidian only. Native testing was performed in an isolated Obsidian 1.14.5 Vault. Automated type checks and tests cover core date, note, feed, reconciliation, and recovery behavior; they do not establish every native UI behavior.

Native QA verified local event and note creation, rescheduling, selected imported-feed changes and recovery/retry flows, note rename handling, Weekly Note editing, Properties behavior, and several calendar/sidebar interactions. Event drag and resize, narrow-window behavior, deeper Year/List layouts, and some provider and week-number paths remain unverified. See [development and QA](https://github.com/rightson/calendar-note/blob/0.1.0/docs/manuals/DEVELOPMENT.md) for the full verified scope and limits.

## Known compatibility limits

Event Note Properties behavior relies on Obsidian editor DOM/CSS details and only runs when the relevant native property panel is available. Daily and Weekly Note provider discovery uses internal provider settings because Obsidian exposes no public provider API; provider changes may affect detection. Mobile behavior has not been verified.
