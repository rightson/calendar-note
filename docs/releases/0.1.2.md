# Calendar-Note 0.1.2

Event Note problems can now be reviewed and fixed in one place instead of being listed as files to fix by hand.

## Event Note problems

- Run **Review Event Note problems**, click **Review and fix** in the scan notice, use the toolbar's **⚠ note problems** button, or choose **Review and fix…** under Settings → Event Note diagnostics.
- Each problem says in plain words what happened: notes sharing one event, copies left after a subscription was re-added, notes from a removed subscription, events a calendar no longer lists, unreadable properties, or a removed `event_id`.
- Notes that claim the same event are shown side by side, with differing properties and lines only one note has highlighted, and an optional line-by-line diff. The likeliest real note is preselected; for each other note choose **Move to trash**, **Add its text to the kept note, then move to trash**, or **Keep as an ordinary note**. The card lists what will happen to every file before you apply it, and warns when trashing would lose text.
- Exact copies can be moved to trash in one step.
- A single problem note can be opened, reconnected to the calendar it belongs to, restored to its last valid properties, kept as an ordinary note, or moved to Obsidian's trash.
- A fix is refused if a note changed after you reviewed it. Notes are moved to Obsidian's configured trash, never deleted outright.

## Install

**Download the [Calendar-Note 0.1.2 ZIP](https://github.com/rightson/calendar-note/releases/download/0.1.2/calendar-note.zip)**, extract it, and replace the `calendar-note` folder in `<Vault>/.obsidian/plugins/`, or update through BRAT. See the [installation guide](https://github.com/rightson/calendar-note/blob/main/docs/manuals/INSTALLATION.md) for safe updates.

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. The fixes are covered by automated tests, and the review dialog was checked in a browser rendering with sample notes; it has not had native Obsidian QA. The [0.1.0 verified scope](https://github.com/rightson/calendar-note/blob/main/docs/releases/0.1.0.md#compatibility-and-verification) still describes what was checked in Obsidian.
