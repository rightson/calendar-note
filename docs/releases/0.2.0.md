# Calendar Pro 0.2.0

Calendar-Note is now **Calendar Pro**. The plugin ID is `calendar-pro` and the GitHub repository is `rightson/obsidian-calendar-pro`.

## Moving from Calendar-Note

Calendar Pro installs as a separate plugin, so Obsidian treats it as new and does not carry over Calendar-Note's settings.

1. Quit Obsidian.
2. Copy `<Vault>/.obsidian/plugins/calendar-note/data.json` (and `recovery.json` if present) into `<Vault>/.obsidian/plugins/calendar-pro/`.
3. Reopen Obsidian, enable **Calendar Pro**, and disable and remove **Calendar-Note**.
4. If you use BRAT, add `rightson/obsidian-calendar-pro` and remove `rightson/calendar-note`.

Your Event, Daily, and Weekly Notes are unchanged.

## Fixes for Community Plugins review

- The Event Note Properties behavior reads the active Markdown view through Obsidian's workspace API.
- The calendar's Week button and sidebar width are styled from the stylesheet instead of inline styles.

## Install

**Download the [Calendar Pro 0.2.0 ZIP](https://github.com/rightson/obsidian-calendar-pro/releases/download/0.2.0/calendar-pro.zip)**, extract it, and copy the `calendar-pro` folder into `<Vault>/.obsidian/plugins/`, or install through BRAT. See the [installation guide](https://github.com/rightson/obsidian-calendar-pro/blob/main/docs/manuals/INSTALLATION.md).

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. The changes are covered by automated tests and have not had native Obsidian QA. The [0.1.0 verified scope](https://github.com/rightson/obsidian-calendar-pro/blob/main/docs/releases/0.1.0.md#compatibility-and-verification) still describes what was checked in Obsidian.
