# Calendar-Note 0.1.3

Each Event Note problem now shows what it affects, not only which file is wrong.

## Event Note problems

- Every problem card names the affected event (its title, date and time, and calendar, including a calendar whose subscription was removed) and says whether the calendar currently shows it.
- It lists every note that links to the notes involved: the event's Daily Note entries, quoted as written, and any other note that links to them, each one click from opening.
- Before you move a note to trash, the card warns which links would then point to a missing note; keeping it as an ordinary note keeps them working.

## Opening notes

- When another pane sits beside the calendar, Daily, Weekly, and Event Notes opened from the calendar open in a new tab in that pane: a calendar on the right opens notes on the left, one on the left opens them on the right, and one in a sidebar opens them in the main area. The calendar is split only when nothing is beside it.

## Install

**Download the [Calendar-Note 0.1.3 ZIP](https://github.com/rightson/calendar-note/releases/download/0.1.3/calendar-note.zip)**, extract it, and replace the `calendar-note` folder in `<Vault>/.obsidian/plugins/`, or update through BRAT. See the [installation guide](https://github.com/rightson/calendar-note/blob/main/docs/manuals/INSTALLATION.md) for safe updates.

## Compatibility and verification

Requires Obsidian 1.14.5 or later on desktop. The changes are covered by automated tests, and the problem cards were checked in a browser rendering with sample notes; they have not had native Obsidian QA. The [0.1.0 verified scope](https://github.com/rightson/calendar-note/blob/main/docs/releases/0.1.0.md#compatibility-and-verification) still describes what was checked in Obsidian.
